# Changelog

## 1.0.0

- Consolidated the supplied multi-generation Genesis-0 tree into one production runtime.
- Added persistent user/workspace/world/agent/event/snapshot schema.
- Added secure password/session/API-key handling.
- Added workspace roles and collaboration.
- Added plan enforcement and admin plan control.
- Added autonomous background simulation supervisor.
- Added deterministic scenario world engine with agent adaptation and event history.
- Added Genesis Console with landing page, dashboard, world registry, Simulation Lab, agent registry, analytics, marketplace templates, workspace access, developer/API tools, plans and admin UI.
- Added Docker, Linux, systemd/Nginx examples and Termux launch path.
- Added end-to-end tests and legacy migration documentation.
